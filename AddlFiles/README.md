# Earlier source drafts

These four files are the drafts that the published book was built from. They are kept for reference and are **not** part of the book.

| File | Status |
| ---- | ------ |
| `BrailleBlaster_Training_Manual.md` | Primary source for the "Why this matters," "Step by step," and "Key takeaways" sections, and for the Instructor Guide. Menu paths agree with the lessons. |
| `BrailleBlaster_Comprehensive_Training_Guide.md` | Used for teaching ideas only. **Do not rely on its menu paths or on its eBraille section.** See `CURRICULUM_REVIEW.md`. |
| `BrailleBlaster_Demonstration_Materials.md` | Not used. Its paste-in demos contain Markdown markers (such as `**bold**`) that would appear literally if pasted into BrailleBlaster. |
| `BrailleBlaster_Training_Supplement_Hands-On_Practice_Guide.md` | Not used. Overlaps with the lessons' practice documents. |

The practice lessons in `my-book/src/lessons` are authoritative where drafts disagree.
