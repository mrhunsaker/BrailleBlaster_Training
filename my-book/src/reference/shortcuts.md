# Keyboard Shortcuts and Menu Paths

Shortcuts and menu paths follow the BrailleBlaster 3.x documentation. If something differs in your version, use **Help > Search**.

## General

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+N` | New document |
| `Ctrl+O` | Open file |
| `Ctrl+P` | Print (Print View to a regular printer) |
| `Ctrl+E` | Emboss (Braille View to an embosser) |
| `Ctrl+Home` / `Ctrl+End` | Go to the beginning / end of the file |
| `Ctrl+G` | Go to a specific page |
| `Alt+Home` | Open the Braille Preview |
| `Alt+P` | Toggle the Print View |
| `Ctrl` plus the plus key / minus key | Increase / decrease font size |

## Emphasis ([Lesson 3](../lessons/03-typeface-emphasis.md))

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italics |
| `Ctrl+U` | Underline |
| `Alt+Shift+S` | Script |
| `Shift+Alt+1` to `Shift+Alt+5` | Transcriber-Defined Typeforms 1 to 5 |
| `Ctrl+Shift+R` | Remove Emphasis from Section |

## Styles and layout ([Lesson 4](../lessons/04-layout-styles.md))

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+R` | Repeat Last Style |
| `Shift+Enter` | Line break (keep text on the same braille line) |
| `Ctrl+Enter` | Page break (force a new braille page) |

## Translation and math

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+M` | Toggle Math Translation ([Lesson 7](../lessons/07-math-translation-toggle.md)) |
| `Ctrl+Shift+T` | Uncontracted Translation of the selection ([Lesson 11](../lessons/11-contraction-relaxer.md)) |
| `Ctrl+D` | Direct Translation of the selection |
| `Ctrl+T` | Correct Braille Translation |
| `Alt+X` | Toggle Six Key Mode |

## Editing and line numbers

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+F` | Find and Replace ([Lesson 12](../lessons/12-find-and-replace.md)) |
| `F2` | Insert line number |
| `Ctrl+F2` | Wrap Prose (for line numbering) |
| `Ctrl+Shift+F2` | Edit line number |
