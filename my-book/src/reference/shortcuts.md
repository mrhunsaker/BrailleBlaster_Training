# Keyboard Shortcuts and Menu Paths

Shortcuts follow **Appendix B** of the BrailleBlaster 3.x User Guide, with the line-numbering and emphasis-removal shortcuts from the guide's own chapters. Menu paths were also checked against the application's source. If something differs in your version, check the **BrailleBlaster User Guide** (`F1`).

## File and view

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+N` | New document |
| `Ctrl+O` | Open a document |
| `Ctrl+W` | Close a document |
| `Alt+F4` | Quit BrailleBlaster |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As (save in a custom location) |
| `Ctrl+P` | Print the Print View to a printer |
| `Ctrl+E` | Emboss |
| `Alt+Home` | Open the Braille Preview |
| `Alt+P` | Toggle the Print View |
| `Ctrl` plus the plus key / minus key | Increase / decrease font size by 1 point |
| `Shift+F10` | Open the context menu (same as a right click) |
| `F1` | Open the BrailleBlaster User Guide |

## Editing

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Cut, copy, paste |
| `Ctrl+F` | Open Find and Replace ([Lesson 12](../lessons/12-find-and-replace.md)) |
| `F3` | Repeat the last search |
| `F7` | Spell check |
| `Shift+Enter` | Insert a line break |
| `Ctrl+Enter` | Insert a page break |
| `Ctrl+5` | Convert selected text to a print page number |
| `Ctrl+Space` | Insert a non-breaking space |
| `Ctrl+R` | Repeat the last style applied |

## Translation and math

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+M` | Toggle Math Translation ([Lesson 7](../lessons/07-math-translation-toggle.md)) |
| `Ctrl+Shift+T` | **Change Translation: Uncontracted**, for the selected text ([Lesson 11](../lessons/11-contraction-relaxer.md)) |
| `Ctrl+D` | **Change Translation: Direct**, for the selected text |
| `Ctrl+T` | Correct Braille Translation ([Lesson 28](../lessons/28-editing-the-translation.md)) |
| `Alt+X` | Six Key Mode on and off |
| `Ctrl+Shift+` ` | Show or hide the **Debug** menu |

The **Contraction Relaxer** has no shortcut.

## Navigation

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+G` | Open the page selection options (**Navigate > Go To Page**) |
| `Ctrl+Home` / `Ctrl+End` | First / last page of the document |
| `Ctrl+Down` / `Ctrl+Up` | Next / previous element |
| `Page Up` / `Page Down` | Next / previous page, as listed in the guide |
| `Alt+End` | Open the Book Tree (NIMAS files) |

## Style loadouts

A **loadout** (see [Lesson 4](../lessons/04-layout-styles.md)) is a set of styles on the number keys. Choose the loadout with `Ctrl+Shift` plus a letter, then press `Alt` plus a number from 1 to 8 to apply the style level in that loadout.

| Shortcut | Loadout |
| -------- | ------- |
| `Ctrl+Shift+B` | Basic |
| `Ctrl+Shift+H` | Heading |
| `Ctrl+Shift+L` | Lists |
| `Ctrl+Shift+P` | Poetry |
| `Ctrl+Shift+A` | Plays |
| `Ctrl+Shift+G` | Glossary |
| `Ctrl+Shift+I` | Index |
| `Ctrl+Shift+E` | Exercise Material |
| `Ctrl+Shift+C` | Caption |
| `Ctrl+Shift+N` | Notes |
| `Ctrl+Shift+U` | Numeric |
| `Ctrl+Shift+M` | Miscellaneous |
| `Alt+1` to `Alt+8` | Apply the style level for the current loadout |
