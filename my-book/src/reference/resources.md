# Resources

## Official BrailleBlaster resources

- [BrailleBlaster home page](https://brailleblaster.org/) and [download page](https://brailleblaster.org/download.php)
- [Documentation hub](https://brailleblaster.org/docs): the User Guide, system requirements, and quick reference cards (PDF and BRF)
- [BrailleBlaster at APH](https://aph.org/brailleblaster)
- [Release notes on GitHub](https://github.com/aphtech/brailleblaster/releases)
- Training videos linked from the User Guide, including *Introduction to BrailleBlaster* and *Getting Started with BrailleBlaster*
- [BrailleBlaster-NG](https://github.com/mwhapples/BrailleBlaster-NG), a community-enhanced version

## Braille standards

- Braille Authority of North America, [*Braille Formats: Principles of Print-to-Braille Transcription, 2016*](https://www.brailleauthority.org/formats/formats2016.html)
- *The Rules of Unified English Braille*
- *The Nemeth Braille Code for Mathematics and Science Notation*, and BANA's guidance on Nemeth within UEB contexts

## File formats and conversion

- [The DAISY Consortium eBraille page](https://daisy.org/activities/standards/ebraille/) and the [eBraille 1.0 specification](https://daisy.github.io/ebraille/published/1.0/)
- [Pandoc](https://pandoc.org/), the universal document converter
- [Liblouis](https://liblouis.io/), the open-source braille translator used by BrailleBlaster

## Community

- The BrailleBlaster feedback form, through the site above
- ACB's *Basics with BITS* sessions on braille translation software, at [bits-acb.org](https://bits-acb.org/)

> [!NOTE]
> Links were checked when this book was prepared. Websites move, so if one fails, start from the BrailleBlaster documentation hub.
