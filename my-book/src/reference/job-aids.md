> [!TIP]

|          |         |                                                     |        | [ ]                      | [ ]              |
|          |         |                                                     |        | [ ]                      | [ ]              |

**Two questions, in order:** (1) Is this about what the learner has been taught? If so, set the Relaxer once for the document. (2) Would contractions change the meaning or make this impossible to read exactly? If so, use Change Translation on that passage.

**Sample note wording:** *Computer code is shown uncontracted so that every character can be read exactly.*

## 7. Production Checklist

Use at the end of every job.

**Before transcribing**
- [ ] I know the braille code, grade, and agency standards for this job.
- [ ] Page properties and translation settings are set ([Lesson 13](../lessons/13-paper-size-and-embossers.md)).
- [ ] I made a copy of the source.

**Structure**
- [ ] Every heading uses a heading style, and the same print level always gets the same braille style.
- [ ] Every list uses a list style at the right level.
- [ ] Boxes, plays, and poems are treated by their function.

**Content**
- [ ] Only meaningful emphasis is carried, and any highlighting or color has a documented transcriber-defined typeform.
- [ ] True math is flagged, and prose hyphens and variables follow a consistent rule.
- [ ] Contractions are relaxed only where the plan says so.
- [ ] Every Find and Replace was previewed first.

**Production**
- [ ] Print page numbers are present, and the Page Change List matches my plan.
- [ ] The running head fits the longest page number.
- [ ] Volume breaks are inserted, and the TOC is dispersed to match.
- [ ] T-pages were generated last, inside the generator window.
- [ ] Transcriber's Notes explain every departure from the print.

**Output**
- [ ] I read the Braille View from first line to last.
- [ ] I tested an emboss on one page before the full job.
- [ ] The BRF or PEF was saved for every volume.
- [ ] I filed the source, the working file, and the output together.

## 9. Proofreading Error Log

For [Lesson 32](../lessons/32-proofreading-and-quality-assurance.md) and every job. One row per error.

| # | Where (page and line) | What the error is | Type | Pass that found it | Fixed in source? | Checked again? |
| - | --------------------- | ----------------- | ---- | ------------------ | ---------------- | -------------- |
|   |                       |                   |      |                    | [ ]              | [ ]            |
|   |                       |                   |      |                    | [ ]              | [ ]            |
|   |                       |                   |      |                    | [ ]              | [ ]            |

**Types:** accuracy, structure, emphasis, page number, notes and captions, math, formatting.

**Passes:** 1 accuracy, 2 structure, 3 emphasis and notes, 4 math, 5 page and volume, 6 the braille itself.

**After the job:** count errors by type. The largest count is where you should look hardest next time.
