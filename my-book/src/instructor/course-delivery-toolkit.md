# Course Delivery and Cohort Management Toolkit

A reusable operating pack for delivering the BrailleBlaster v3 Training course across cohorts. It standardizes preparation, pacing decisions, attendance records, learner evidence, skills review, and end-of-course reporting without changing the existing lesson sequence.

Use one copy of the registers per cohort. Keep learner records in an access-controlled location; this public curriculum repository is a template library, not a student information system.

> [!WARNING]
> Keep cohort registers, learner progress records, assessment evidence, and reports in an access-controlled system approved by your organization. Do not store identifiable learner or student records in this public repository or copy completed records into shared teaching templates.

### Standard status vocabulary

Use the same values in all trackers.

- **Not started** — no evidence submitted.
- **In progress** — work has begun; competency not yet demonstrated.
- **Meets** — required performance is demonstrated with acceptable evidence.
- **Exceeds** — performance is accurate, independent, and includes defensible decisions or anticipation of edge cases.
- **Not yet** — evidence shows a gap requiring practice or remediation.
- **Not assessed** — no assessment opportunity has occurred.
- **Waived / not applicable** — instructor-approved exclusion; record the reason.

Do not treat attendance, completion of a worksheet, or self-reported confidence as proof of skill. Record observable evidence separately.

### Pacing review and change control

At the end of each session, compare actual time with plan and record:

1. Which outcomes were demonstrated and which were only introduced?
2. Which learners need additional guided practice?
3. What must be revisited before the next dependent lesson or lab?
4. Is the variance caused by learner practice, software/version differences, accessibility needs, equipment, or instructor pacing?
5. What will change in the next session, and who owns the action?

Do not compress the debrief or quality-assurance checks merely to recover schedule. If a session runs long, record the deferred content and reschedule it explicitly.

### Dashboard calculations and interpretation

- **Meets-or-better rate** = (Meets + Exceeds) / (Meets + Exceeds + Not yet + In progress). Exclude Not assessed and approved N/A from this performance denominator; report the unassessed count separately.
- **Assessment coverage** = learners with a recorded result / active cohort size.
- **Attendance rate** = total attended session places / total scheduled learner-session places, using the cohort's published attendance policy.
- **Completion rate** = learners meeting every published completion requirement / learners enrolled at the cohort's defined census date.
- **Remediation open** = count of learners with at least one unresolved Not yet result.

Always display numerator, denominator, and cohort size alongside percentages. A high pass rate with low assessment coverage is not evidence of cohort-wide mastery. Disaggregate only where group sizes and privacy rules permit.

## 7. Administration cadence

| When | Required action | Record updated |
| --- | --- | --- |
| Before enrollment closes | Confirm prerequisites, cohort setup, delivery plan, assessment rules, and secure record location | Cohort setup |
| Before each session | Prepare sample files, software, equipment, access arrangements, and session plan | Pacing tracker |
| During each session | Record attendance and objective evidence; note technical or delivery issues | Attendance and session record |
| After each session | Update actual pacing, learner milestones, remediation, and carry-forward actions | Pacing and learner registers |
| At each unit boundary | Review skills matrix; plan targeted practice for Not yet / In progress results | Learner register and dashboard |
| Before course close | Score capstone, review portfolios, resolve evidence gaps, apply published completion rules | Learner register |
| After course close | Aggregate cohort results, complete report, assign improvement actions, archive securely | End-of-course report |

## 8. Quality and records safeguards

- Publish completion and attendance rules before the cohort begins; apply them consistently.
- Use the existing course assessment rubrics and portfolio review guide. Record the rubric version and any approved local adaptation.
- Distinguish **Not assessed** from **Not yet**. Missing evidence is not a failing performance result, but it must not be reported as competency.
- Record remediation and reassessment rather than overwriting the original result.
- Keep instructor answer keys and evaluator references separate from student-facing materials where needed.
- Restrict access to identifiable learner records and evidence. Follow the institution's retention, deletion, and disclosure requirements.
- Report cohort-level results only when aggregation protects learner privacy.
- Treat this toolkit as an administrative aid. It does not certify braille transcription, replace expert review, or supersede *Braille Formats 2016*, UEB, Nemeth, agency policy, or the course's assessment rubrics.
