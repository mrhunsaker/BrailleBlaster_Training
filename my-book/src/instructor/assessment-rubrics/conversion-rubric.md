# Source Conversion Comparison Rubric

| Criterion | 4 — Strong | 3 — Competent | 2 — Developing | 1 — Inadequate |
|---|---|---|---|---|
| Semantic analysis | Identifies meaningful source structure | Mostly accurate | Misses some structure | Treats all formatting as equivalent |
| Conversion comparison | Tests and records losses systematically | Records main differences | Incomplete comparison | No evidence-based comparison |
| Remediation | Corrects issues with rationale | Corrects most issues | Partial fixes | Unjustified or damaging changes |
| Verification | Compares source and output thoroughly | Checks key content | Spot checks only | No meaningful QA |
| Documentation | Reproducible workflow log | Usable notes | Gaps | No useful record |
