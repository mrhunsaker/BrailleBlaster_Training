# Practical Assessment: Remediation and Retest Record

Use this record when an assessment identifies a competency gap or critical defect. Define the gap in observable terms, assign a practice activity, and specify the evidence required to close it. A retest should assess the same competency using a fresh or equivalent specimen, not simply repeat the original answer.
