# Teaching Notes: Unit 4: Specialized Content

These notes support Lessons 25 to 32. The lessons are independent, so teach them in the order your learners need. The [unit page](../units/unit-4-specialized.md) suggests where each one fits among the earlier lessons.

## Lesson 25: Tables

**Read the lesson:** [Tables](../lessons/25-tables.md).

### Teaching strategy and practice design

**Strategy.** Start with a print table and ask what a reader does with it. Then let learners discover that the *same data* can be presented four ways. The decision is the lesson, and the Table Editor is only the tool.

**Common pitfalls and fixes**

- Typing the table in the Print View → use **Insert > Table** and the Table Editor.
- Editing table text in the Print View → it will not accept edits. Reopen the Table Editor, with the cursor inside the table.
- Leaving out the Transcriber's Note when the format changes → Listed, Stairstep, and Linear all need one.
- Guessing whether a Simple table fits → read **Total Width** and compare it with the cells per line.
- Using Reformat Table to fix a layout problem → it turns the table into plain text and cannot be undone by the editor.

**Going further.** Custom column widths, one or two cells between columns, guide dots, row headings, Swap Columns and Rows, and Advanced Reformat.

**Practice tiers**

- *Beginner:* Build a three-column Simple table.
- *Intermediate:* Choose and justify a type for a wide table, with its note.
- *Advanced:* Restructure a table that does not fit, and explain every change to the reader.

### Check for understanding

- Chooses a type and can say why, using the page width.
- Writes the Transcriber's Note for a changed format.
- Edits only through the Table Editor.

## Lesson 26: Controlling the Page with Style Options

**Read the lesson:** [Controlling the Page with Style Options](../lessons/26-controlling-the-page.md).

### Teaching strategy and practice design

**Strategy.** Show the problem first: a heading stranded at the bottom of a page. Then teach the option that fixes it. Each option answers a question about the *braille page*.

**Common pitfalls and fixes**

- Using options to rebuild a style → apply the right style first.
- Applying Set Cell Position to a paragraph → it moves one line only.
- Forgetting that Lines Before = 2 means one blank line → the count is the value minus one.
- Using a blank page to make pages face → use Page Side, because it keeps working after later edits.

**Going further.** Interpoint facing-page planning, Skip Number Lines with running heads and guide words, and combining Don't Split with Keep With Next.

**Practice tiers**

- *Beginner:* Add a line break and a blank line.
- *Intermediate:* Keep a heading with its text and a list on one page.
- *Advanced:* Plan facing pages for a table in an interpoint volume.

### Check for understanding

- Names the right option for each page problem.
- Verifies every option in the Braille Preview.
- Explains when a Style Option is the wrong tool.

## Lesson 27: Images and Tactile Graphics

**Read the lesson:** [Images and Tactile Graphics](../lessons/27-images-and-tactile-graphics.md).

### Teaching strategy and practice design

**Strategy.** Ask *what is this image for?* before touching a tool. Learners who start with the tool describe everything and plan nothing.

**Common pitfalls and fixes**

- Applying the Description style to part of the text → highlight the whole item first.
- Typing Transcriber's Note indicators into a Description → the style adds them.
- Reserving a whole page of lines → the number must be fewer than lines per page.
- Describing what the image means and not what it shows.

**Going further.** Attaching image files, updating a placeholder, tactile graphics on a ViewPlus embosser, and facing-page planning.

**Practice tiers**

- *Beginner:* Reserve space and add a caption.
- *Intermediate:* Write a description and apply the correct style.
- *Advanced:* Decide among description, graphic, and omission for a set of figures.

### Check for understanding

- Separates the print caption from the transcriber's description.
- Chooses a treatment for each image, with a reason.
- Keeps descriptions objective.

## Lesson 28: Editing the Translation

**Read the lesson:** [Editing the Translation](../lessons/28-editing-the-translation.md).

### Teaching strategy and practice design

**Strategy.** Give learners a decision table before any practice: which tool acts on what? Most mistakes in this lesson are picking the right tool for the wrong scope.

**Common pitfalls and fixes**

- Saving a correction **globally** with a real name in it → it is submitted to APH. Practice locally.
- Using Correct Word for a single character that has no braille → use Define New Character.
- Expecting Six Key text to be translated → it is not.
- Deleting the wrong entry in View Corrections → read it first.

**Going further.** Entry methods (Six Key or ASCII), editing earlier corrections, and running Spell Check before translation.

**Practice tiers**

- *Beginner:* Type three cells in Six Key Mode.
- *Intermediate:* Use Direct and Uncontracted on a selection.
- *Advanced:* Define a symbol and a proper noun, then review and delete the corrections.

### Check for understanding

- Chooses the right tool for each case.
- Explains the difference between Locally and Globally.
- Removes a correction cleanly.

## Lesson 29: UEB Technical Material

**Read the lesson:** [UEB Technical Material](../lessons/29-ueb-technical-and-numeric-material.md).

### Teaching strategy and practice design

**Strategy.** Begin with a question: *which code does this student read?* Then show where that decision lives. Do not teach braille-code rules the lesson only needs learners to locate.

**Common pitfalls and fixes**

- Mixing Nemeth indicators into a UEB Technical document → use one family of tools.
- Setting the default code mid-document → set it once, at the start.
- Treating Numeric Series as a layout tool → it replaces spaces with dot 5.

**Going further.** EBAE, Spanish US, and Cherokee Plus Nemeth, and what each requires of a transcriber.

**Practice tiers**

- *Beginner:* Find the Translation Settings.
- *Intermediate:* Compare the same expression under two math tables.
- *Advanced:* Set up and verify a document for an agency's required code.

### Check for understanding

- States the required code before starting.
- Uses the matching indicator tools.
- Verifies in the Braille View.

## Lesson 30: Line Numbers

**Read the lesson:** [Line Numbers](../lessons/30-line-numbers.md).

### Teaching strategy and practice design

**Strategy.** A short, procedural lesson. Do it in one session, with every learner inserting, editing, and removing a number.

**Common pitfalls and fixes**

- Inserting numbers in text that has not been wrapped → Wrap Prose, or Poetic Stanza for verse.
- Numbering lines the print does not number.
- Forgetting Apply before Next.

**Going further.** Increments, poetry versus prose, and NIMAS files that arrive pre-numbered.

**Practice tiers**

- *Beginner:* Wrap and insert one number.
- *Intermediate:* Number every fifth line.
- *Advanced:* Edit and remove numbers across a whole passage.

### Check for understanding

- Wraps before inserting.
- Sets the start and increment.
- Edits a number with Apply and Done.

## Lesson 31: Glossaries and Indexes

**Read the lesson:** [Glossaries and Indexes](../lessons/31-glossaries-and-indexes.md).

### Teaching strategy and practice design

**Strategy.** Have learners find the pattern in the margins before telling them the formula. Then connect the emphasis tool to the *reason* in Braille Formats.

**Common pitfalls and fixes**

- Running the emphasis tool before applying the Glossary or Index style → it works on designated sections.
- Not saving first → the guide advises it.
- Forgetting to restore emphasis on foreign words.
- Adding guide words before pagination is final.

**Going further.** Multi-level glossaries, the experimental Alphabetic Reference tools, and guide words.

**Practice tiers**

- *Beginner:* Apply a one-level glossary style.
- *Intermediate:* Format a two-level index and check its margins.
- *Advanced:* Predict the margins for a three-level index, then verify.

### Check for understanding

- Chooses the style for the number of levels.
- Removes entry-word emphasis and restores what is needed.
- Explains why guide words come last.

## Lesson 32: Proofreading and Quality Assurance

**Read the lesson:** [Proofreading and Quality Assurance](../lessons/32-proofreading-and-quality-assurance.md).

### Teaching strategy and practice design

**Strategy.** Do the seeded-error exercise *cold*, with no teaching first. Learners' misses show them which passes they need. Then teach the passes.

**Common pitfalls and fixes**

- Proofreading right after transcribing → rest first.
- Fixing errors in a BRF → fix the BBX and export again.
- Reading for meaning and not for errors → separate passes.
- Skipping the log → the log shows which errors a transcriber makes.

**Going further.** Second readers, sampling for long documents, and building an agency checklist from a log.

**Practice tiers**

- *Beginner:* Find the structure errors.
- *Intermediate:* Find all twelve and classify them.
- *Advanced:* Build a checklist from your own error pattern.

### Check for understanding

- Works in separate passes.
- Fixes at the source.
- Keeps and uses an error log.
