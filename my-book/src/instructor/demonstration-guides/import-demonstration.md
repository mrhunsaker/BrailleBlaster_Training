# Demonstration: Import and Conversion Triage

Use a Markdown, XML, HTML, or LaTeX specimen from the supplemental source pack.

1. Inspect the source before importing.
2. Identify headings, lists, tables, figures, math, notes, and metadata.
3. State which semantics should survive conversion.
4. Import using the course workflow.
5. Compare imported structure with source.
6. Correct one structural defect and one conversion artifact.
7. Save a working copy and record changes.

Ask learners: What would you verify if appearance looked correct but navigation was wrong? What evidence would justify choosing a different source format?
