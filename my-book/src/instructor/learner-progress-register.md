# Learner Progress Register

## Purpose and handling

This is an instructor-controlled tracking template. Use a restricted program system for identifiable learner records. In copies shared beyond the instructional team, use approved learner identifiers or aggregate data only. Do not commit completed registers containing personal information to a public repository.
