# Assignment Answer Guide

## A01–A03: Source structure and editing
- A01: Expect semantic headings, consistent paragraphs, and preservation of all source wording. Distinguish formatting cleanup from editorial rewriting.
- A02: Intended hierarchy: Field Guide (level 1), Before/After planting (level 2), and Materials/Prepare the trays/Observation schedule (level 3). Nested lists retain parent-child relationships.
- A03: Only exact TEMP-CODE occurrences should change. “Temporary code review” is a negative control. Emphasis should follow the marked source, not instructor interpretation.

## A04–A05: Mathematics and spatial work
- A04: Distinguish expressions used operationally from symbols discussed as text. Evaluate context boundaries and verification method, not a particular toggle sequence.
- A05: The number line shows seven ordered, equally spaced integer positions, with -2 filled and 1 open. Direction and interval inclusion must be conveyed without color dependence.

## A06–A09: Import and special structures
- A06: Strong comparisons distinguish semantic preservation, formatting preservation, and conversion defects. Students record manual remediation.
- A07: The XML is well-formed but uses generic/inconsistent element names. A valid answer proposes a consistent mapping (title, section, heading, paragraph, list, list item, note) and tests import. Tag renaming requires a schema or mapping rationale.
- A08: Speaker labels, stage directions, stanza boundaries, and boxed-note status remain distinguishable in linear reading.
- A09: Assess metadata, navigation, reading order, semantic structure, accessibility alternatives, and target-reader compatibility independently.

## A10–A16: Production and QA
- A10: No single volume count is prescribed. Logical boundaries, measured pagination, TOC distribution, cross-volume navigation, and specification compliance matter.
- A11: Preserve header/data relationships. Linearization may be appropriate if it improves access and retains all relationships; require a rationale.
- A12: G1 is likely decorative. G2, G3, G5, and G6 carry instructional information and need accessible treatment. G4 depends on context; G7 should be assessed for functional meaning.
- A13: Prefer the least-invasive evidence-based solution. Global settings require document-wide evidence; source errors should be queried rather than silently corrected.
- A14: Cross-references, volume scope, and final page references must be verified after pagination.
- A15: Use the seeded-error blueprint as the expected inventory. Award credit only when students cite source evidence and verify corrections.
- A16: Evaluate workflow documentation, not just the final artifact. Unresolved issues must be disclosed.
