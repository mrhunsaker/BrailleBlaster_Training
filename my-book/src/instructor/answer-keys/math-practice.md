# Math and Technical Practice: Instructor Notes

Assess context identification, rule selection, scope of context, accuracy checks, and documentation. Do not use an unverified literal braille transcription as a universal answer key.

For the mixed passage, students separate operational arithmetic/equations from prose that mentions symbols. For the number line, verify order, equal spacing, endpoint distinction, direction, and a nonvisual explanation. For the technical set, require citations to current code guidance consulted for decimals, signs, units, ratios, dates, URLs, formulas, file names, and software versions.

Common misconceptions:
- Treating every occurrence of a mathematical symbol as mathematical context.
- Extending math context beyond its intended scope.
- Assuming visual layout is self-explanatory.
- Applying a global translation adjustment to a local source problem.
- Failing to verify output in context after editing.
