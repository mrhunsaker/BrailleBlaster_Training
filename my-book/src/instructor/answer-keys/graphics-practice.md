# Graphics Practice: Instructor Notes

A sound decision is based on instructional purpose, not a rule that every image must become a tactile graphic or every image can be replaced by a sentence.

- G1: Decorative motif; usually no description unless it conveys information elsewhere.
- G2: Labeled flower parts; preserve component names and spatial relationships, often with tactile or combined treatment.
- G3: Trend and outlier are data relationships; provide accessible data/description and consider tactile representation when graph interpretation is a learning objective.
- G4: Contextual photograph; description depends on whether meaningful details are referenced.
- G5: Circuit topology and polarity are essential; tactile or structured accessible representation is likely needed.
- G6: Route, legend, and location relationships must be conveyed; tactile map or structured route description may be appropriate.
- G7: Repeated icon; describe functional warning only if the icon adds meaning not already in text.

For the flower brief, assess orientation, label placement, line distinction, uncluttered layout, and useful verbal orientation.
