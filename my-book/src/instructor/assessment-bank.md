# Instructor Assessment Bank

Use these prompts as short checks, oral questions, exit tickets, or written assessments. Adapt them to the current BrailleBlaster version and applicable production specification.

## Foundation
1. Why should a heading be semantic rather than merely bold?
2. What is the risk of using manual spaces to imitate a list?
3. How can a find/replace operation be made safer?
4. What evidence shows emphasis was preserved?
5. What should be checked after importing a Word document?

## Import and conversion
6. What is the difference between preserving appearance and preserving semantics?
7. Which source features should be inventoried before conversion?
8. What would make XML easier to map reliably?
9. Why should conversion be tested on a representative sample?
10. What should an import log record?

## Math and technical material
11. How do you distinguish a symbol mentioned in prose from one used mathematically?
12. Why is context scope important?
13. What verification evidence should accompany a technical translation decision?
14. What must a spatial number line communicate nonvisually?

## Production
15. What evidence should determine volume boundaries?
16. When should a TOC be regenerated?
17. What does a T-page communicate, and what specification governs it?
18. How can a table be made understandable if a grid is not the best reading format?
19. What makes an image description instructional rather than decorative?

## Quality assurance
20. What belongs in a useful error log?
21. Why should a correction be checked in surrounding context?
22. What is the difference between a source error and a transcription error?
23. What should be done when the production specification is ambiguous?
24. What evidence is required before sign-off?

## Applied scenarios
25. An imported document has correct-looking headings but no usable navigation. Diagnose the likely issue.
26. A local symbol problem appears in one equation only. Explain why a global setting may be inappropriate.
27. A volume break splits a heading from its first paragraph. Propose a correction and downstream checks.
28. A figure is referenced in a question but its description omits the trend being tested. Explain the impact.
29. A cross-reference points to a page in a previous pagination draft. Describe the repair.
30. A final proofreading pass finds a correction that may alter meaning. What escalation path is appropriate?
