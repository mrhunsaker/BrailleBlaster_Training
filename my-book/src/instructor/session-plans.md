# Session Plans

Ready-to-run plans for instructor-led groups. The first four come from the original Trainer's Guide, updated to use the [Drill Bank](../reference/drill-bank.md). The rest use the [labs](../labs/index.md).

Every plan follows the same rhythm from the [Instructor Guide](index.md): demonstrate, practice together, practice alone, and debrief with the Braille View open.

> [!TIP]
> Keep a spare, finished copy of every practice document on a shared drive so a learner who falls behind can catch up without missing the debrief.

## Core sessions

### Session 1: Text formatting fundamentals (90 minutes)

**Lessons:** [1](../lessons/01-navigating-the-interface.md) and [3](../lessons/03-typeface-emphasis.md).

1. **Demonstrate (15 min).** Walk through the interface, then the emphasis demonstration.
2. **Guided practice (25 min).** Work drills A1 to A4 together.
3. **Independent practice (30 min).** Learners do A5 to A8.
4. **Debrief (20 min).** Discuss A6 (the highlighting and the transcriber-defined typeform) and A7 (decoration versus meaning).

### Session 2: Layout styles (90 minutes)

**Lessons:** [4](../lessons/04-layout-styles.md), [5](../lessons/05-heading-levels.md), and [6](../lessons/06-list-formatting.md).

1. **Demonstrate (15 min).** Apply styles with Breadcrumbs visible.
2. **Guided practice (25 min).** Work drills B1 to B3 together. B3 is the false-list trap.
3. **Independent practice (30 min).** Learners do B4 and B5.
4. **Debrief (20 min).** Read three Breadcrumbs trails aloud and verify each style.

### Session 3: Math translation basics (120 minutes)

**Lesson:** [7](../lessons/07-math-translation-toggle.md).

1. **Demonstrate (20 min).** Flag math, then Block versus Inline.
2. **Guided practice (35 min).** Work drills C1 to C3 together.
3. **Independent practice (40 min).** Learners do C4 and C5.
4. **Debrief (25 min).** Check the Braille View for correct Nemeth indicators and discuss the agency-convention items.

### Session 4: The ASCII Math Hub (120 minutes)

**Lesson:** [8](../lessons/08-ascii-math-hub.md).

1. **Demonstrate (20 min).** Build a fraction, then a nested exponent.
2. **Guided practice (35 min).** Build C6 to C8 together using the Hub.
3. **Independent practice (40 min).** Learners do C9 to C12.
4. **Debrief (25 min).** Compare the ASCII Math input with the Braille View output.

## Production sessions

### Session 5: Rescue a Word document (120 minutes)

**Lessons:** [2](../lessons/02-opening-word-documents.md) and [12](../lessons/12-find-and-replace.md). **Lab:** [Lab 1](../labs/lab-1-rescue-word-document.md).

Open sample files 01 and 02 side by side (20 min). Teach the Three-Pass Method (15 min). Learners work Parts B and C of the lab (60 min). Debrief with the notes each learner would send back to the author (25 min).

### Session 6: Page setup and the test emboss (90 minutes)

**Lesson:** [13](../lessons/13-paper-size-and-embossers.md). **Lab:** [Lab 5](../labs/lab-5-test-page-and-embosser.md).

Show real paper and interpoint samples (10 min). Learners do Parts A and B (35 min). Run the test emboss in small groups, one embosser at a time (30 min). Debrief on naming and maintenance (15 min).

### Session 7: Importing formats (120 minutes)

**Lessons:** [14](../lessons/14-importing-markdown-and-opendocument.md) to [17](../lessons/17-what-pandoc-does.md). **Labs:** [Lab 2](../labs/lab-2-import-comparison.md) and [Lab 3](../labs/lab-3-when-latex-misbehaves.md).

Ask learners to write their prediction table (10 min). Run Lab 2 (50 min). Run Lab 3 (40 min). Debrief by listing the first three checks for each format (20 min).

### Session 8: NIMAS (90 minutes)

**Lesson:** [20](../lessons/20-nimas-production-files.md). **Lab:** [Lab 4](../labs/lab-4-nimas-style-file.md). **Reading:** [Policy and Standards Background](../reference/policy-background.md).

Open with the policy context (15 min). Run the lab (55 min). Debrief on which decisions belong in agency standards (20 min).

### Session 9: Page numbers and running heads (90 minutes)

**Lesson:** [21](../lessons/21-running-heads-and-page-numbers.md). **Lab:** [Lab 6](../labs/lab-6-running-heads-and-page-numbers.md).

Have learners fill in the plan before opening the software (15 min). Run the lab (50 min). Debrief on the places where no tool made the decision (25 min).

### Session 10: Relaxing and replacing (90 minutes)

**Lessons:** [11](../lessons/11-contraction-relaxer.md) and [12](../lessons/12-find-and-replace.md). **Labs:** [Lab 7](../labs/lab-7-relaxation-plan.md) and [Lab 8](../labs/lab-8-find-and-replace-cleanup.md).

Run Lab 8 first because its trap is quick and memorable (40 min). Run Lab 7 (40 min). Debrief on documenting decisions (10 min).

### Session 11: Special structures (90 minutes)

**Lessons:** [6](../lessons/06-list-formatting.md) and [18](../lessons/18-advanced-formatting.md). **Lab:** [Lab 9](../labs/lab-9-special-structures.md).

Start with print examples of each structure and ask what each one *does* (15 min). Run the lab (60 min). Debrief on the "is it really a box?" test (15 min).

### Session 12: Tables (120 minutes)

**Lesson:** [25](../lessons/25-tables.md).

Start with a printed table and ask what a reader does with it (10 min). Demonstrate the Table Editor and the five types (25 min). Learners build Tables A and B and record the Total Width (50 min). Debrief on which type each table needs, and on the Transcriber's Note (35 min).

### Session 13: Page, images, and translation fixes (120 minutes)

**Lessons:** [26](../lessons/26-controlling-the-page.md), [27](../lessons/27-images-and-tactile-graphics.md), and [28](../lessons/28-editing-the-translation.md).

Show a stranded heading and fix it with Keep With Next (20 min). Reserve space for a figure and apply the Caption and Description styles (30 min). Use the decision table in Lesson 28 for four translation problems, saving corrections **locally** only (40 min). Debrief on scope: what each tool changes (30 min).

### Session 14: Proofreading (90 minutes)

**Lesson:** [32](../lessons/32-proofreading-and-quality-assurance.md).

Hand out the seeded-error exercise **cold**, with no teaching first (25 min). Teach the six passes (15 min). Learners repeat the exercise, using the error log, and compare (30 min). Debrief on which error types each learner missed (20 min).

### Session 15: Capstone workshop (4 hours, with a break)

**Project:** [Capstone](../capstone/capstone.md).

Learners complete tasks 1 to 6 in the first half, then the notes, volumes, T-pages, and output in the second. Use the rubric to give feedback while they work, not only at the end.

## Adapting a plan

- **Shorter sessions:** split a plan at the guided-practice break. Never cut the debrief.
- **Larger groups:** pair learners for practice, and have each pair explain one decision aloud.
- **Learners with assistive technology:** allow extra time for tasks that move between views, and let them choose the view arrangement that works for them ([Lesson 1](../lessons/01-navigating-the-interface.md)).
