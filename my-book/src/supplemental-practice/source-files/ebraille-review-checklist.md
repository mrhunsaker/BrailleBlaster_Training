# eBraille Publication Review Checklist

- [ ] Publication title and creator metadata are present and accurate.
- [ ] Language metadata is appropriate.
- [ ] Reading order is logical.
- [ ] Navigation landmarks and table of contents are usable.
- [ ] Heading hierarchy is coherent.
- [ ] Lists and tables preserve relationships.
- [ ] Images have appropriate alternatives or documented treatment.
- [ ] Page navigation features are present when required.
- [ ] No production-only notes remain unintentionally.
- [ ] File opens in the intended reading environment.
- [ ] Accessibility is checked in compatible reading systems where feasible.

Record defects with severity, location, expected behavior, observed behavior, and proposed correction. Do not infer conformance solely from a file extension.
