# Translation-Edit Decision Cases

For each case, identify context, applicable guidance, least-invasive corrective action, and verification step. Do not apply a global change to solve a local problem without evidence.

1. A technical term is correct in most of a chapter but incorrect in one occurrence.
2. A symbol appears differently in a displayed equation and ordinary prose.
3. A proper name is contracted in a way that obscures intended spelling.
4. A recurring pattern appears throughout a document and may reflect an import or style issue.
5. A source contains an apparent typographical error that affects meaning.
6. A requested change conflicts with the stated production specification.

Record whether the case calls for a local edit, source correction request, document-level setting review, transcriber's note, or supervisor consultation. Justify the choice.
