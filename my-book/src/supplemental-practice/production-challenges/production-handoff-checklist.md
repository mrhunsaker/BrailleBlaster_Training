# Production Handoff Checklist

- [ ] Correct source and specification versions identified.
- [ ] Originals preserved; working files clearly named.
- [ ] Import/conversion workflow documented.
- [ ] Heading and list hierarchy verified.
- [ ] Emphasis and special structures checked.
- [ ] Math/technical contexts reviewed.
- [ ] Tables and figures reviewed for meaning and accessibility.
- [ ] Running heads and page numbering checked.
- [ ] TOC and cross-references verified.
- [ ] Volume breaks and preliminary pages checked.
- [ ] Proofreading completed against source.
- [ ] Embosser/output sample checked where required.
- [ ] Error log closed or unresolved items assigned.
- [ ] Final files named, organized, and delivered.
- [ ] Handoff note records assumptions and outstanding issues.
