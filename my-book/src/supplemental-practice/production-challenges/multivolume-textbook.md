# Multi-Volume Textbook Planning Challenge

## Scenario
A fictional science textbook contains 12 chapters, 18 tables, 14 figures (including two data plots and one labeled process diagram), a glossary, an index, and front matter with title page, contents, and introduction.

The production specification calls for manageable physical volumes, consistent running heads, preliminary pages, a complete contents strategy, and a final QA record. No fixed volume count is supplied.

## Student task
1. Identify logical division points and propose a volume count.
2. Explain how to estimate and verify volume length.
3. Plan contents placement and cross-volume navigation.
4. Identify running-head content and page-numbering requirements.
5. Determine how the T-page generator will be used, if required.
6. Flag tables and figures needing special handling.
7. Identify glossary and index implications across volumes.
8. Specify proofing and embossing sample plans.

| Decision | Proposed approach | Evidence needed |
|---|---|---|
| Volume boundaries |  | Actual pagination and section structure |
| TOC distribution |  | Final volume count and contents |
| Running heads |  | Production specification |
| Preliminary pages |  | Agency/template requirements |
| Figures/tables |  | Content and accessibility review |
| Glossary/index |  | Cross-volume references |
| QA |  | Proofread and output checks |

A defensible plan is more important than guessing a target sheet count. Revise it when actual pagination or production constraints provide new evidence.
