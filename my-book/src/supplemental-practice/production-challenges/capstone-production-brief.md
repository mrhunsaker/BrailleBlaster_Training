# Capstone Production Brief: Small Textbook Job

## Client brief
You are assigned a fictional 36-page instructional chapter titled *Water Systems*. The source package contains headings, nested lists, two tables, three figures, one equation, a glossary excerpt, and a short index. One source file has inconsistent heading semantics and another contains a malformed list.

## Required workflow

### Intake
- Record source filenames, formats, versions, and supplied specifications.
- Preserve originals and create working copies.
- List missing information and questions for the requester.

### Source assessment
- Identify semantic structure and conversion risks.
- Compare available source formats.
- Identify content requiring manual review.

### Production
- Import or recreate the content.
- Apply structural styles and appropriate translation workflows.
- Review tables, figures, equation, notes, and lists.
- Plan layout, pagination, running heads, and volume boundaries as required.

### Quality assurance
- Compare output with source.
- Complete a seeded-error audit.
- Verify navigation and cross-references.
- Produce a final error log and sign-off.

## Handoff package
1. Final project/export in the instructor-requested format.
2. Source assessment and workflow log.
3. Table and figure decision records.
4. Pagination/volume plan.
5. Completed QA checklist and error log.
6. Handoff note listing unresolved issues and assumptions.

Acceptance requires complete content, coherent structure, documented translation decisions, justified accessibility decisions, production compliance, and explicit disclosure of unresolved questions.
