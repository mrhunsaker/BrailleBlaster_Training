# Seeded-Error Exercises

Use these scenarios for proofreading and QA practice. The repository provides a defect blueprint; instructors can seed the defects in a BrailleBlaster project/export or create a local exercise. The text files are not prebuilt project files.

- [Seeded-error set and defect blueprint](seeded-error-set.md)
- [Student error log template](error-log-template.md)

Instructor correction notes are in the instructor answer-key folder. Distribute them separately when assessment integrity matters.
