# Seeded-Error Exercises

Twelve individual defect scenarios are provided as student-facing practice files. They can be assigned separately or combined into a proofreading assessment. The repository also includes a [defect blueprint](seeded-error-set.md) and [student error log template](error-log-template.md).

- [E01 — Heading hierarchy](E01-heading-hierarchy.md)
- [E02 — Nested list level](E02-nested-list.md)
- [E03 — Emphasis scope](E03-emphasis-scope.md)
- [E04 — Find-and-replace collateral change](E04-find-replace.md)
- [E05 — Math context boundary](E05-math-context.md)
- [E06 — Missing table header](E06-table-header.md)
- [E07 — Incomplete figure description](E07-figure-description.md)
- [E08 — Inconsistent running head](E08-running-head.md)
- [E09 — Volume break at heading](E09-volume-break.md)
- [E10 — Production note in reader output](E10-production-note.md)
- [E11 — Broken glossary cross-reference](E11-glossary-reference.md)
- [E12 — Proofreading regression](E12-proofread-regression.md)

Instructor correction notes are in the instructor answer-key folder. Distribute them separately when assessment integrity matters. The individual scenarios are text-based prompts, not prebuilt BrailleBlaster project files.
