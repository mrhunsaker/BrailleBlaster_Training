## Use and distribution
Use synthetic names and data. Never place confidential student records or personally identifying information in practice files. If this repository is student-accessible, distribute instructor answer keys separately or keep them in a private repository.

The source specimens are text-based examples (Markdown, HTML, XML, and LaTeX), not prebuilt BrailleBlaster projects or certified braille transcriptions. Students should create working copies and verify results against the current code and job specification.
