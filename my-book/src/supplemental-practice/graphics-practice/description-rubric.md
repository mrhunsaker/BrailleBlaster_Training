# Image Description Rubric

| Criterion | 4 — Strong | 3 — Competent | 2 — Developing | 1 — Inadequate |
|---|---|---|---|---|
| Purpose | Communicates instructional role | Mostly clear | Vague | Absent |
| Essential information | Preserves all needed relationships/data | Minor omission | Important omission | Misrepresents figure |
| Concision | Efficient and prioritized | Slightly wordy | Distracting detail | Unfocused |
| Orientation | Clear spatial organization | Mostly clear | Some ambiguity | Disorienting |
| Consistency | Matches labels and surrounding text | Minor mismatch | Multiple mismatches | Contradicts source |

Score each criterion and provide one evidence-based revision suggestion. A high score does not replace tactile production review when a tactile graphic is required.
