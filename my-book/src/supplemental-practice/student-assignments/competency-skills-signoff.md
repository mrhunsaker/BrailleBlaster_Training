# Competency Skills Sign-Off

Use this sheet to record observed performance. A sign-off means the learner demonstrated the behavior under the stated conditions; it does not mean the topic was merely covered. Add evidence-log identifiers or project filenames for each decision.

Rating key: **N/O** = not observed; **D** = developing; **M** = meets; **E** = exceeds. A skill should be signed off at M or E. If performance is D, document the practice and reassessment required.
