## Assignment briefs

### A01 — Import and normalize a Word source
Use the Word-source specimen in the source pack. Import or recreate it, normalize inconsistent headings, paragraphs, emphasis, and list structure, and preserve all wording. Submit the project, a source-to-structure map, and at least five corrections. Check that headings are semantic and list levels are consistent.

### A02 — Styles, headings, and nested lists
Use the structured-content specimen. Apply heading levels and represent nested procedures and unordered lists correctly. Submit the project and an outline of the resulting hierarchy. Check navigation and parent-child list relationships.

### A03 — Emphasis and find/replace audit
Use the emphasis-audit specimen. Apply only source-indicated emphasis. Replace exact occurrences of TEMP-CODE with REVIEW-CODE in a working copy. The phrase “temporary code review” is a negative control. Submit a change log and verify zero unintended matches.

### A04 — Mixed literary and mathematical passage
Use the mixed-math passage. Mark mathematical expressions and context boundaries before translating. Explain three context decisions and verify the expressions against the source. Do not assume every numeral or symbol belongs to a displayed equation.

### A05 — Spatial number line and layout
Construct the number line described in the math practice pack. Submit the project, layout plan, and proofing notes. Verify tick order, spacing, labels, endpoints, direction, and a nonvisual explanation.

### A06 — Import-format comparison
Complete the [Energy in Our Community multi-format source-pack lab](../source-files/multi-format-source-pack-lab.md). Compare Markdown, HTML, XML/NIMAS, LaTeX, CSV, and EPUB specimens using the course workflows. Record semantic preservation, formatting changes, conversion losses, and manual remediation. Submit import logs and one corrected project.

### A07 — Repair a semantic XML source
Inspect the XML specimen, propose a consistent element mapping, repair a working copy, and document each change before importing. Submit the corrected XML, change log, and resulting project. Confirm well-formedness and meaningful structure.

### A08 — Format a play, poem, and boxed note
Use the special-structures specimen. Preserve speaker labels, stage directions, stanza boundaries, and boxed-note status. Submit a structure decision table and proofread excerpt. Check that the result remains clear when read linearly.

### A09 — eBraille structure review
Evaluate the hypothetical publication package using the eBraille review checklist. Assess metadata, navigation, reading order, semantic hierarchy, and target-reader compatibility separately. Submit a prioritized remediation list.

### A10 — Multi-volume contents planning
Use the multi-volume textbook scenario. Propose logical volume boundaries, contents placement, running heads, page numbering, and T-page requirements. Treat sheet counts as estimates and verify actual pagination. Submit a volume plan and production checklist.

### A11 — Table analysis and reconstruction
Classify each supplied table and reconstruct it using an appropriate strategy. Explain any linearization decision. Verify every header/data relationship and ensure no data is omitted or reordered.

### A12 — Figure decision and description plan
For each figure scenario, choose description, tactile graphic, simplified representation, combined treatment, or documented omission. Draft descriptions and a tactile production brief where appropriate. Explain what information is essential to the learning objective.

### A13 — Translation-edit decision log
Use the translation-edit cases. Choose among a local adjustment, document-level setting review, source correction request, transcriber's note, or supervisor consultation. Prefer minimal, evidence-based changes and verify in context.

### A14 — Glossary, index, and line-number check
Review the glossary/index specimen. Identify entries, cross-references, line-number requirements, and navigation issues. Submit a structure plan and QA checklist. Verify page references after pagination.

### A15 — Seeded-error proofreading
Use the seeded-error blueprint. Record each defect's location, source evidence, category, severity, correction, and verification. Submit a corrected project and final error log. A correction is not closed until surrounding context is checked.

### A16 — End-to-end production simulation
Complete the production capstone brief from intake through handoff. Submit the source assessment, project, table/figure decisions, pagination plan, error log, QA sign-off, and handoff note. Disclose unresolved questions and assumptions.

## General submission checklist
- [ ] Original source retained unchanged.
- [ ] Working copy and project named clearly.
- [ ] Structural elements use appropriate semantic styles/tools.
- [ ] Translation decisions documented and verified.
- [ ] Layout, pagination, running heads, and volume boundaries checked.
- [ ] Tables, figures, and special structures reviewed.
- [ ] Final proofread completed against the source.
- [ ] Known limitations and unresolved issues recorded.


These templates are designed to be completed with the course's fictional practice materials; replace assumptions only when an actual job specification supplies authoritative requirements.
