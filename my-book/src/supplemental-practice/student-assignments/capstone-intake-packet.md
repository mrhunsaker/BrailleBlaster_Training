# Capstone Production Intake Packet

Use this packet before opening BrailleBlaster. It simulates the intake stage of a real accessible-text production job. The scenario and data are fictional.

## Job request

**Client:** North Valley Learning Services  
**Project:** Grade 7 science, Unit 3 — Energy and Motion  
**Requested format:** UEB literary with Nemeth Code for mathematics  
**Primary output:** Embossed braille, BRF files, and editable BrailleBlaster project  
**Reader profile:** Student reads contracted UEB and Nemeth; prefers clear hierarchy and concise, informative figure descriptions  
**Requested delivery:** 3 weeks after approved source receipt  
**Source package:** `brailleblaster-source-practice-bundle.zip` plus the capstone chapter in the course

The client says: “Please make the chapter match the print book, keep all important diagrams, and split it into volumes that are easy to carry. We need the files ready for embossing.”

This request is not yet a complete production specification. Identify what must be clarified rather than silently guessing.
