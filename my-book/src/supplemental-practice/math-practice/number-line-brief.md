# Spatial Number-Line Construction Brief

Create a horizontal number line from -3 through 3 inclusive.

Requirements:
- Seven equally spaced integer tick marks.
- Labels for every integer.
- A filled point at -2.
- An open point at 1.
- A directional indication showing movement from -2 to 1.
- A concise text alternative stating the essential mathematical relationship.

Extension: Add a second representation of the interval (-2, 1]. Explain the open and closed endpoints.

Proofing questions:
1. Are labels aligned with the correct ticks?
2. Is direction unambiguous?
3. Can endpoint inclusion be determined without color?
4. Does the text alternative communicate the same information?
