# Lesson 46: Image Description and Tactile Graphics: Methods and Resources

> **Lesson at a glance**
>
> - **Unit:** Unit 5: Handbook (Supplemental)
> - **Suggested time:** about 2 hours
> - **Prerequisites:** [Lesson 22](22-transcribers-notes.md), [Lesson 27](27-images-and-tactile-graphics.md)
> - **You will need:** A computer, and the sample files from the [Sample Files](../samples/index.md) page where a lesson uses them.

## Learning objectives

By the end of this lesson you will be able to:

- Write an objective description of a chart, a map, a diagram, and a photograph, in a consistent order.
- Decide whether an image needs a description, a tactile graphic, both, or neither, and defend the decision.
- Describe the main ways a tactile graphic is produced, and where the guidelines are.
- Find and use the main published guidelines and tools for image description and tactile graphics.

> [!IMPORTANT]
> Describe what the image communicates, not what you assume the author intended. Distinguish visible facts from interpretation, preserve relevant labels and relationships, and ask the content expert when a description would require subject-matter inference.

## Why this matters

[Lesson 27](27-images-and-tactile-graphics.md) taught you the **tools** for images in BrailleBlaster: the placeholder, the Caption and Description styles, and the page controls. It did not teach you **how to describe a picture well**, which is the harder skill. A description that is long and unfocused wastes the reader's time. One that is short and wrong misleads. A good one gives the reader what a sighted classmate gets from the picture, no more and no less.

This lesson teaches the method, and points to the published guidelines that are the authority.

## The Concept

### Start with the purpose

Before you describe anything, ask: **why is this image here?** The same photograph of a pond can be decoration in a story, evidence in a science lesson, or the subject of an art class, and each needs a different description. If you can, ask the teacher, or read the sentence that refers to the figure.

| The image is… | Describe… |
| ------------- | --------- |
| **Decoration** | Usually nothing. Say so in your notes. Some agencies require a brief mention |
| **Illustration** of something the text already says | Briefly. The text carries the content |
| **Data** (a chart or graph) | The type, the axes and units, the values, and the pattern |
| **A diagram or model** | The parts, their names, and how they connect |
| **A map** | The area, the key, the features, and their relations |
| **A photograph or artwork the lesson depends on** | What matters for the lesson, then the visible details |

### A reliable order

A description is easier to read, and easier to compare between images, if it follows the same order each time. A common one is:

1. **What it is.** The kind of image and its subject: *a bar chart of monthly rainfall.*
2. **An overview.** The main point or pattern in one or two sentences.
3. **The details.** The parts, values, labels, and relations, in a **fixed order**, for example **left to right and top to bottom**.
4. **Any text in the image,** such as labels, a title, or a key. Read it out.

### Be objective

- **Describe what is there, not what you think it means.** Say *the line rises steadily*, not *the economy improved*, unless the text says so.
- **Do not begin with "image of" or "picture of."** The reader already knows it is an image.
- **Use the words the lesson uses.** If the text calls the parts *roots* and *stems*, so should you.
- **Give numbers.** Report values and units. A chart whose bars are described only as "tall" and "short" has lost its data.
- **Say what is not visible**, if it matters, such as *the vertical axis does not start at zero.*
- **Keep it as short as it can be** and still give the reader what the lesson needs.

### Three levels of description

| Level | Length | Used for |
| ----- | ------ | -------- |
| **Alt text** | A phrase or a sentence | A short label, stored with the image ([Lesson 27](27-images-and-tactile-graphics.md)) |
| **Short description** | A short paragraph | Most images in a textbook |
| **Long description** | Several paragraphs, or a structured list | A complex chart, a map, or an image the lesson relies on |

### When a description is not enough

A description is a good fit for **content**. A **tactile graphic** is a better fit when **spatial relationships are the point**: a map, a geometric figure, a diagram of a circuit, a graph the student needs to plot or read by position. Often the best answer is **both**: the graphic for the layout and a description for the labels and the explanation.

| Question | If the answer is… |
| -------- | ----------------- |
| Can the key information be said in words? | **Yes**: a description may be enough |
| Does the student need to see *where things are*, or *how they connect*? | **Yes**: consider a tactile graphic |
| Will the student be *asked to produce or analyze* a similar figure? | **Yes**: a tactile graphic is likely needed |
| Is the image decorative? | **Yes**: omit it, with a note if your rules require |
| Is the student able to read tactile graphics, and has the graphic been tested? | **No**: rely on the description, and arrange instruction |

## Tactile graphics

A tactile graphic is a raised version of an image. The main ways of making one, in outline:

| Method | In brief |
| ------ | -------- |
| **Braille embosser with graphics ability** | Raised dots form lines and shapes on braille paper. BrailleBlaster supports this on ViewPlus embossers ([Lesson 27](27-images-and-tactile-graphics.md)) |
| **Swell paper** | The image is printed or copied onto special paper and heated, so the black areas rise |
| **Thermoform** | A plastic sheet is molded over a model |
| **Collage and handmade** | Materials such as textured paper and string are glued to a base |
| **3D printing** | A printed model, used for objects and shapes |

The choice depends on the budget, the equipment, the student, and how many copies are needed. A tactile graphic is **not** a copy of the print image. It is a **redesigned** image, simplified to what fingers can read: fewer lines, larger labels, and a key. The published guidelines say how.

### Proofread the graphic

A tactile graphic needs a proofreader who is a **skilled tactile reader**, and ideally the student's own team. A graphic that looks right to a sighted person may be unreadable by touch. Make the check part of the job, as you do for braille ([Lesson 32](32-proofreading-and-quality-assurance.md)).

## Step by step

### Describe an image

1. **State the purpose.** Why is the image here? Ask if you can.
2. **Choose the level:** alt text, short, or long.
3. **Write the first sentence:** what it is.
4. **Write the overview:** the main point.
5. **Write the details** in a fixed order, with numbers and units.
6. **Read the text in the image**, including the title and the key.
7. **Cut.** Remove anything the lesson does not need and anything that is interpretation.
8. **Read it aloud**, or have someone who cannot see the image read it and tell you what they picture.
9. **Put it in the Description style** ([Lesson 27](27-images-and-tactile-graphics.md)).

## Practice

The three images are given as specifications. Write the description for each, **in the order described above**.

### Image A: a bar chart

```text
Title: "Rainfall by Month, Mill Town"
Type: vertical bar chart, four bars, left to right
Horizontal axis: Month (January, February, March, April)
Vertical axis: Rainfall in millimeters, from 0 to 100, marked every 20
Bar values: January 78, February 64, March 71, April 55
A dotted horizontal line is drawn at 70, labeled "Average"
```

### Image B: a diagram

```text
Title: "Parts of a Flower"
Type: labeled line drawing of one flower on a stem
Labels, top to bottom: petal, stamen, pistil, sepal, stem
The stamen is drawn on the left of the pistil; both are inside the petals
Leader lines run from each label to its part
```

### Image C: a map

```text
Title: "Route of the School Bus"
Type: simple map; north is at the top
Features: School (top right), Library (top left), Park (center), Station (bottom)
A line runs from the Station up through the Park to the School; a side branch from the Park leads left to the Library
A key says: solid line = bus route
```

### Tasks

1. Write the description for each image.
2. For each, say what the **purpose** is, and whether a tactile graphic is also worth considering.
3. In Image A, what would you add if the lesson asked students to compare each month with the average?
4. Rewrite this sentence to make it objective: *"The chart shows that the weather was good in April."*
5. Name two things that would make a description for Image C too long.

### Answer Key

1. **Model descriptions.** Yours need not match word for word. Check them against the checklist below.
   - **A.** *Bar chart titled "Rainfall by Month, Mill Town." Four bars show rainfall in millimeters, on a scale of 0 to 100. The bars are, from left to right: January 78, February 64, March 71, April 55. A dotted line at 70 is labeled "Average." Rainfall is highest in January and lowest in April.*
   - **B.** *Labeled drawing titled "Parts of a Flower," showing one flower on a stem. The labels, from top to bottom, are petal, stamen, pistil, sepal, and stem. The stamen is on the left of the pistil, and both are inside the petals.*
   - **C.** *Map titled "Route of the School Bus," with north at the top. The Library is at the top left, the School at the top right, the Park in the center, and the Station at the bottom. A solid line, the bus route, runs from the Station up through the Park to the School. A branch from the Park leads left to the Library.*
2. **A:** data, so a description with the values. A tactile graphic is optional, if the student is learning to read graphs. **B:** a diagram of parts, where a description may be enough, and a tactile graphic helps if the *positions* matter. **C:** a map, where the layout is the point. A **tactile graphic with a description** is the strongest choice.
3. State **which months are above and below 70**: January 78 and March 71 are above, and February 64 and April 55 are below. A reader should not have to work that out from the numbers.
4. *"In April, the bar for rainfall is 55 millimeters, the lowest of the four months."* The original interprets ("good weather") what the data does not say.
5. Any two of: describing the **style** of the symbols (colors and shapes) that the lesson does not use; listing every possible **distance or direction**; describing the **decoration**, such as a border or compass rose, that has no purpose; repeating the key's words in several places.

**Checklist for a good description.** It says what the image is. It gives the main point. It follows a fixed order. It gives numbers and units. It reads the labels. It does not interpret. It is as short as the purpose allows.

## Key takeaways

- **Purpose first.** Ask why the image is there before you describe it.
- Use a fixed order: **what it is, the overview, the details** (left to right, top to bottom), **the text**.
- **Be objective.** Describe what is there, give numbers and units, and do not interpret.
- A description suits **content**. A **tactile graphic** suits **spatial relationships**. Often use both.
- A tactile graphic is a **redesigned** image, and it must be **proofread by a tactile reader**.
- Use the published guidelines: **the DIAGRAM Center**, **NCAM/WGBH**, **BANA's tactile graphics guidelines** (2010, with a 2022 revision), and **Path to Literacy**.
