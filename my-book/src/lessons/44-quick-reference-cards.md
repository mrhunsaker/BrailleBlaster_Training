# Lesson 44: Quick-Reference Cards

> **Lesson at a glance**
>
> - **Unit:** Unit 5: Handbook (Supplemental)
> - **Suggested time:** about 90 minutes
> - **Prerequisites:** [Lesson 33](33-what-makes-a-good-source.md), [Lesson 41](41-text-encoding-and-braille-characters.md)
> - **You will need:** A computer, and the sample files from the [Sample Files](../samples/index.md) page where a lesson uses them.

## Learning objectives

By the end of this lesson you will be able to:

- Use one-page cards for the indicator cells you meet most often, for both UEB and Nemeth.
- Keep print-source cards for Markdown, Word, LibreOffice, Google Docs, XML, and PDFs close at hand.
- Decode and encode a few indicators from their dot numbers.
- Use the cards correctly: as reminders, and not as a replacement for the code books.

## Why this matters

A transcriber looks up the same dozen things over and over: which indicator comes before a bold word, what the cell for a fraction line is, which shortcut makes a Heading 1. The answer is usually in a big book or a long lesson. A one-page card puts the answer where you need it.

This lesson is a set of cards. Print them, braille them, or keep them in a window beside BrailleBlaster.

## How to use this lesson

The **braille cards** list indicators as dot numbers, as Unicode cells, and as Braille ASCII. All three were generated from the dot numbers by the formula in [Lesson 41](41-text-encoding-and-braille-characters.md), so they agree with one another. The **print-source cards** repeat the key results of Lessons 33 to 42 in one place.

> [!IMPORTANT]
> **These cards are reminders and not the rules.** They list the *cells* for common indicators. They do not say **when** to use them, and the rules for that are long. For the rules, read *The Rules of Unified English Braille* and the *Nemeth Braille Code*, and check every card against your copy of the book. The cards were prepared for this course and have not been reviewed by a certified transcriber. Treat any difference as a mistake in the card.

### Card 5: Braille ASCII

The full 64-cell table is in [Lesson 41](41-text-encoding-and-braille-characters.md). Three facts to remember:

- For the letters *a* to *z*, Braille ASCII is the capital letter.
- The capital sign (dot 6) is `,` and the numeric indicator (dots 3456) is `#`.
- The Braille ASCII digit `1` is **dot 2**, not the numeral one.

## Print-source cards

### Card 6: Markdown ([Lesson 34](34-markdown-syntax-guide.md))

| You want | Write | In BrailleBlaster |
| -------- | ----- | ----------------- |
| Centered heading | `# Title` | Centered Heading |
| Cell 5 heading | `## Section` | Cell 5 Heading |
| Cell 7 heading | `### Sub` (and deeper) | Cell 7 Heading |
| A line break in a poem | End the line with `\` | A real line break |
| Margins 3-1 | `::: {custom-style="3-1"}` … `:::` | Those margins |
| A blank line | `::: {custom-style="BB Empty Paragraph"}` `:::` | A blank line |
| A page break | `::: {custom-style="BB Page Break"}` `:::` | A page break |
| **Avoid** | `\|` line blocks | The import **fails** |
| **Avoid** | An image alone on a line | **Dropped**, with its caption |
| **Avoid** | `~~strikethrough~~`, `H~2~O`, `x^2^` | Lost, or literal characters |

### Card 7: Word ([Lesson 35](35-word-structure-with-styles.md))

| Action | Windows |
| ------ | ------- |
| Heading 1, 2, 3 | `Ctrl+Alt+1`, `2`, `3` |
| Normal | `Ctrl+Shift+N` |
| Apply Styles box | `Ctrl+Shift+S` |
| Styles pane | `Alt+Ctrl+Shift+S` |
| Formatting marks | `Ctrl+Shift+8` |
| Reveal Formatting | `Shift+F1` |
| Navigation Pane | `Ctrl+F` |
| Page break | `Ctrl+Enter` |
| Equation | `Alt+=` |
| Check Accessibility | **Review > Check Accessibility** |

**Rules:** no fake headings. Pictures *in line with text*, with alt text. Save as `.docx`.

### Card 8: LibreOffice and Google Docs ([Lesson 36](36-libreoffice-openoffice-and-google-docs.md))

| Action | LibreOffice | Google Docs |
| ------ | ----------- | ----------- |
| Heading 1, 2, 3 | `Ctrl+1`, `2`, `3` | `Ctrl+Alt+1`, `2`, `3` |
| Body text | `Ctrl+0` | `Ctrl+Alt+0` |
| Styles | `F11` | the style box |
| Heading outline | `F5` (Navigator) | **View > Show document outline** |
| Formatting marks | `Ctrl+F10` | not available |
| Bullets / numbers | `Shift+F12` / `F12` | `Ctrl+Shift+8` / `Ctrl+Shift+7` |

**Save as `.docx`** to keep margin style names, empty paragraphs, and page breaks.

### Card 9: XML and XPath ([Lessons 37](37-reading-xml.md) and [38](38-dtbook-nimas-and-mathml.md))

| Task | Command or query |
| ---- | ---------------- |
| Is it well-formed? | `xmllint --noout file.xml` |
| Pretty-print | `xmllint --format file.xml` |
| All headings | `//d:h1 \| //d:h2` (bind `d` to the DTBook namespace) |
| Count page numbers | `count(//d:pagenum)` |
| Any element by name, any namespace | `//*[local-name()='h1']` |

**DTBook headings:** `h1` Centered, `h2` Cell 5, `h3` to `h8` Cell 7. `doctitle` and `docauthor` go to the head.

### Card 10: Inside a Word file ([Lesson 39](39-inside-the-packages.md))

```bash
unzip -p f.docx word/document.xml | grep -o 'w:pStyle w:val="[^"]*"' | sort | uniq -c
unzip -p f.docx word/document.xml | grep -o '<wp:anchor' | wc -l
unzip -p f.docx word/document.xml | grep -o 'w:txbxContent' | wc -l
```

No `pStyle` at all means the structure is fake. `wp:anchor` is a floating picture. `w:txbxContent` is a text box.

### Card 11: PDFs and OCR ([Lesson 42](42-pdfs-scans-and-ocr.md))

```bash
pdfinfo f.pdf               # Tagged: yes or no
pdffonts f.pdf              # no fonts: a scan
pdftotext f.pdf out.txt     # default order, not -layout
pdftoppm -r 300 -png f.pdf page
tesseract page-1.png out -l eng
```

### Card 12: the ten import-safety rules ([Lesson 33](33-what-makes-a-good-source.md))

1. No image alone in its paragraph. 2. No Markdown line blocks. 3. Metadata and titles do not import. 4. Headings collapse: 1, 2, then 3 to 6. 5. The Word *Title* style is not a heading. 6. Strikethrough is dropped. 7. Subscripts and superscripts are literal outside math. 8. Inline code breaks a paragraph. 9. Hard-wrapped text is one paragraph per line. 10. Illegal XML characters are deleted.

## Practice

### Tasks

1. Using Card 1, give the dot numbers and the Unicode cells for a **capital word indicator**.
2. Using Card 2, write the cells that open an **italic word** and a **bold passage**.
3. What ends a bold passage? Write its dots.
4. Card 4 gives the cells for a fraction. Write the three cells in order, and say what each is.
5. What is the Braille ASCII text for the capital sign followed by the letter *a*?
6. A card and your code book disagree. Which do you trust, and what do you do next?
7. Which print-source card answers: "Why did my picture and its caption disappear?"

### Answer Key

1. Two cells, each of **dot 6**: ⠠⠠.
2. An italic word: prefix dots 46 then suffix dot 2, which is ⠨⠂. A bold passage: prefix dots 45 then suffix dots 2356, which is ⠘⠶.
3. The **bold terminator**: dots 45 then dot 3, which is ⠘⠄.
4. ⠹⠌⠼: the fraction **open** (dots 1456), the fraction **line** (dots 34), and the fraction **close** (dots 3456).
5. `,A`: the capital sign is the comma, and the letter *a* is the capital `A`.
6. **The code book.** Then correct the card, and tell whoever maintains this course. A wrong card is worse than none.
7. **Card 12**, rule 1, with Cards 6 and 7 for the fix: put the image inside a sentence, or in the same paragraph as its caption.

## Key takeaways

- A card is a **reminder**. It lists the cells, and not the rules for using them. The code books decide.
- Every UEB typeform has a **prefix** (italic 46, bold 45, underline 456, script 4) and a **suffix** (symbol 23, word 2, passage 2356, terminator 3).
- The capital sign is dot 6, the numeric indicator is dots 3456, and the grade 1 indicator is dots 56.
- Nemeth fractions use **open**, **line**, and **close**: dots 1456, 34, and 3456.
- Keep the print-source cards beside your keyboard until the commands are habit.
