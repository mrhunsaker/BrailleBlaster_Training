# UEB Practice 00: BrailleBlaster GUI Orientation

## Purpose

This guided practice establishes the interface skills needed for every later BrailleBlaster exercise. Complete it before beginning the formatting and translation practices. It complements [Lesson 1: Navigating the BrailleBlaster Interface](../lessons/01-navigating-the-interface.md); the lesson explains the concepts, while this page provides a repeatable skills check.

## Learning outcomes

By the end of this practice, you can identify Print View, Braille View, and Style View; show, hide, and rearrange views; distinguish a display change from a document-content change; open Braille Preview and navigate its pages; move through document elements; and save an editable BBX working file.

## Preparation

1. Launch the installed BrailleBlaster 3.x release and record its version.
2. Create a new document with File > New (Ctrl+N).
3. Save it as GUI-Orientation-Practice.bbx in your practice folder.
4. Keep this page available for copying the sample text.

## Sample passage

Paste the following passage into Print View:

    BrailleBlaster Orientation

    This is the first body paragraph. It gives the learner a safe place to inspect the Print, Braille, and Style views.

    This second paragraph is deliberately longer. It should wrap in the braille display, allowing the learner to compare the print text with its translated representation and to move through the document by element.

    Final paragraph: use this text to confirm that navigation reaches the end of the document.

## Guided tasks

### Task 1: Identify the three views

1. Locate Print View, Braille View, and Style View.
2. Place the insertion point in the first paragraph in Print View.
3. Observe the corresponding location in the other views.
4. Record which view accepts ordinary print-text editing and what information each other view provides.

**Expected result:** Print View is the editing surface for ordinary text. Braille View displays the translation. Style View identifies the structure or style applied to the current element.

### Task 2: Change the view arrangement

1. Open View > Toggle Views.
2. Hide Style View, then show it again.
3. Open View > Toggle Views > Rearrange Views.
4. Move Braille View to a different position using the available move controls.
5. Restore your preferred arrangement.

**Expected result:** You can hide and restore views and explain where a restored view appears. At least one view remains visible.

### Task 3: Compare braille display modes

1. Note the current appearance of Braille View.
2. Toggle View Braille from the View menu.
3. Compare the display before and after the change.
4. Restore the original display mode.

**Expected result:** The display changes between braille cells and ASCII representation. This is a viewing preference; it does not rewrite the source text.

### Task 4: Open and inspect Braille Preview

1. Open File > Braille Preview (or use Alt+Home where supported).
2. Inspect the page layout and status information.
3. Locate the page-navigation controls.
4. Navigate by ordinal page number. If the document has print or braille page numbering, compare those navigation modes as well.
5. Return to the editing window.

**Expected result:** You can distinguish a page's ordinal position from its print or braille page number. A short practice document may not contain enough pagination differences to make the values diverge.

### Task 5: Navigate by structure

1. In Print View, use Navigate > Home (Ctrl+Home).
2. Use Next Element and Previous Element to move between the title and paragraphs.
3. Use Navigate > End (Ctrl+End) and return to the beginning.
4. Use Go To Page (Ctrl+G) if available in the installed version.

**Expected result:** You can move through structural elements without relying exclusively on line-by-line cursor movement.

### Task 6: Save and verify

1. Save the BBX file.
2. Close it and reopen it from the practice folder.
3. Confirm that the sample text remains intact.
4. Confirm that the three views are available and that Braille Preview opens.
5. Do not export BRF or PEF for this orientation task; those formats are covered in the embossing and export lesson.

**Expected result:** The saved BBX reopens with the sample passage intact. Your work is saved in the editable source format.

## Knowledge check

1. Which view is used to edit ordinary print text?
2. What does Braille View let you verify?
3. Does toggling the braille display representation change the underlying document?
4. Why should you save an editable BBX before exporting a BRF?
5. What is the difference between ordinal page number and print page number?
6. What should you do if a menu label differs in your installed version?

## Answer guide

1. **Print View.** It is the ordinary text-editing surface.
2. **The translated braille representation.** Compare it with the source and assignment requirements.
3. **No.** It changes how the translation is displayed, not the document content.
4. **BRF is a delivery representation, not the normal editable working source.** Preserve the BBX so corrections can be made in the source document.
5. **Ordinal page number** is the page's position in the document; **print page number** is the print pagination value assigned to that page. They can differ.
6. **Consult the user guide for the installed release, record the version, and verify the equivalent operation.** Do not assume a remembered menu path is current.

## Completion standard

Complete every guided task and answer all six knowledge-check questions. The instructor should observe the learner performing the view changes, preview navigation, structural navigation, and save/reopen cycle. A verbal description alone is not evidence of hands-on proficiency.

## Version note

Menu names and shortcuts can vary between BrailleBlaster releases and operating systems. This practice follows the 3.x course documentation. Where a command differs, use the installed application's Help/User Guide and record the verified path before teaching it to another learner.
