# How to Use This Course

## The practice method

Almost every lesson has a **Practice Document** in a code block. The method is always the same:

1. Create a new BrailleBlaster document (`Ctrl+N`).
2. Copy the practice block using the copy button on the code block, and paste it into the **Print View**.
3. Do the tasks the lesson describes.
4. Check the **Braille View** every time you change something.
5. Compare your result with the **Answer Key**.

Pasted plain text arrives as Body Text with no formatting. This is deliberate. Real transcription begins with plain text too, and you must decide the structure from context or from a legend that describes the print source.

> [!NOTE]
> Some practice blocks use a plain-text markup key (for example `**word**` for bold). That key is only a stand-in so the print emphasis is unambiguous. It is not real formatting, and the asterisks should not appear in your braille.

## Conventions

- **Menu paths** are bold with a greater-than sign: **File > Open**.
- `Keyboard shortcuts` are in code style: `Ctrl+M`.
- *Italics* mark new terms and on-screen labels.
- Section numbers such as §4.2.1 refer to *Braille Formats 2016* unless a lesson says otherwise.
- Callouts flag important information:

> [!TIP]
> A shortcut or habit worth building.

> [!NOTE]
> Extra context that explains a choice.

> [!IMPORTANT]
> Something that causes real mistakes if you skip it.

## Working habits that matter everywhere

- **Edit in the Print View, check in the Braille View.** See [Lesson 1](../lessons/01-navigating-the-interface.md).
- **Choose what the text is, not how it looks.** Apply styles instead of spaces.
- **Keep the original.** Work from a copy of any source file.
- **Save often,** and keep a dated copy before any large Replace All.
- **Verify after every import.** Opening a file is not the same as finishing a transcription.
- **Explain unusual decisions** in a Transcriber's Note.

## Accessibility and assistive technology

Braille transcription is work that blind and sighted people both do, and many learners use screen readers and braille displays. Practice blocks and answer keys in this course are plain text and tables, so they can be read linearly. Lessons describe structure in words as well as through layout.

How well a specific screen reader works with a specific BrailleBlaster release can vary. During [Lesson 1](../lessons/01-navigating-the-interface.md), try the orientation exercise with your own setup and note anything that does not work. Share findings with your instructor or with the BrailleBlaster project.
