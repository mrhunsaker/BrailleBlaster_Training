# Unit 4: Specialized Content

Units 1 to 3 teach the core of BrailleBlaster and the production workflow. Unit 4 covers the **specialized content and finishing skills** that real textbooks need: tables, page control, images, translation corrections, alternative math codes, line numbers, glossaries and indexes, and proofreading.

These eight lessons are written to stand alone. Each lists its own prerequisites, so you can teach them in a different order, or only the ones your learners need.

## A note on tools that are hidden in 3.x

Lessons 23 and 24 (in Unit 3) and Lesson 31 mention tools that live in a hidden **Debug** menu in the current 3.x releases. Press `Ctrl+Shift+` ` to show it. Lesson 19 also mentions an experimental eBraille exporter in the same place. This unit's lessons use only the documented 3.x tools, except where they say so.

## Unit outcomes

When you finish this unit you can:

- Build a table, choose the right table type, and explain a changed format to the reader.
- Control page breaks, facing pages, and blank pages with Style Options.
- Reserve space for graphics, and keep captions and descriptions apart.
- Fix a translation problem with the correct tool and save the correction safely.
- Set up a document for UEB Technical Material or Nemeth within UEB.
- Number the lines of prose and poetry.
- Format glossaries and indexes, and remove the emphasis print adds.
- Proofread in passes, log errors, and fix them at the source.

## Unit 4 checkpoint

This checkpoint should take about two hours.

**The task.** Using a short source of your choice, with at least one table and one figure and a three-entry glossary:

1. Build the table, choose its type, and write the Transcriber's Note if the format changes (Lesson 25).
2. Reserve space for the figure and write its description in the correct style (Lesson 27).
3. Apply a Glossary style and remove the emphasis from the entry words (Lesson 31).
4. Set one Style Option to keep a heading with the text that follows it (Lesson 26).
5. Correct the translation of one proper noun and save it **locally** (Lesson 28).
6. Proofread the result in passes and complete an error log with at least five entries (Lesson 32).

**You are ready for the capstone** when your error log shows that you found and fixed your own errors at the source.
